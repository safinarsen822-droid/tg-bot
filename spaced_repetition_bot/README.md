# Telegram-бот для интервального повторения

Бот-напоминалка, реализующий технику интервального повторения (spaced repetition) для эффективного запоминания информации.

## Как это работает

1. Вы отправляете боту любую информацию, которую хотите запомнить (тему, факт, формулу, слово и т.д.)
2. Бот сохраняет эту информацию как тему для повторения
3. Бот напоминает вам повторить тему через оптимальные интервалы: 1 день → 3 дня → 7 дней → 14 дней → 30 дней
4. Каждый раз, когда вы успешно повторяете тему, интервал увеличивается
5. Если вы забыли материал - прогресс сбрасывается и мы начинаем с первого интервала
6. После успешного прохождения всех интервалов тема считается выученной

## Установка и запуск

### Требования

- Python 3.11 или выше
- Telegram Bot Token (получите у @BotFather)

### Шаги установки

1. Склонируйте репозиторий или скачайте файлы
2. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```
3. Создайте файл `.env` в корневой директории проекта и добавьте туда ваш токен бота:
   ```
   BOT_TOKEN=ваш_токен_здесь
   ```
   Получить токен можно у @BotFather в Telegram

4. Запустите бота:
   ```bash
   python main.py
   ```

## Использование

### Основные команды

- `/start` - приветствие и инструкция
- `/help` - подробная справка о работе бота
- `/list` - показать список всех ваших тем
- `/timezone <часовой_пояс>` - настроить ваш часовой пояс (например, Europe/Moscow, UTC+5)
- `/delete <ID>` - удалить тему по ID
- `/pause <ID>` - приостановить напоминания для темы
- `/resume <ID>` - возобновить напоминания для темы

### Добавление тем

Просто отправьте боту любое текстовое сообщение - оно будет сохранено как тема для повторения.
Например:
```
Неправильные глаголы английского
Формула квадратного уравнения
Столица Франции
```

### Работа с напоминаниями

Когда приходит время повторения, бот отправит вам сообщение с inline-кнопками:

- ✅ Повторил - вы успешно вспомнили материал
- 😓 Забыл(а) - вы не вспомнили, прогресс сбрасывается
- ⏰ Отложить на 1 час - напомнить снова через час

## Интервалы повторения

Бот использует следующие интервалы (в днях):
- 1 день
- 3 дня
- 7 дней
- 14 дней
- 30 дней

После пятого повторения (через 30 дней после четвёртого) тема считается выученной.

## Технические детали

- **Язык**: Python 3.11+
- **Библиотека Telegram**: aiogram 3.x
- **База данных**: SQLite (через aiosqlite)
- **Планировщик**: Периодический опрос БД каждую минуту
- **Хранение настроек**: Переменные окружения (.env файл)

## Структура проекта

- `main.py` - точка входа, запуск бота
- `db.py` - работа с базой данных
- `handlers.py` - обработчики команд и сообщений
- `scheduler.py` - фоновая задача для отправки напоминаний
- `config.py` - конфигурация и загрузка настроек
- `requirements.txt` - зависимости проекта
- `.env` - файл с токеном бота (не включается в репозиторий)

## Логирование

Бот ведет логирование ключевых событий:
- Создание новых тем
- Отправка напоминаний
- Ошибки отправки (например, если пользователь заблокировал бота)
- Изменения этапов повторения

## Примечания

- Бот поддерживает нескольких пользователей одновременно
- Данные хранятся в SQLite базе данных, поэтому при перезапуске бота никакие напоминания не теряются
- Часовой пояс по умолчанию: Europe/Moscow (UTC+3), но можно изменить через команду /timezone
